# AI Comparison

A collection of pet shop landing page variants ("The Happy Tails") generated in different styles for side-by-side comparison.

## What this repository contains

Each HTML file is a standalone landing page implementation using:
- HTML
- JavaScript
- Tailwind CSS via CDN

## Project structure

- `ChatGPT-5.3-Codex.html`
- `GPT-5.1-Codex-Max.html`
- `ClaudeSonnet4.5.html`
- `Deepseek.html`
- `Gemini3.0.html`
- `GLM4.5.html`
- `Grok 4.1 Fast Reasoning (XAI).html`
- `kimi2.5.html`
- `Mistral Large 3.html`
- `opus4.6.html`
- `qwen-3-max.html`
- `prompt.txt` (source prompt used for generation)

## How to run

1. Clone or download this repository.
2. Open any `.html` file in your browser.
3. Compare layout, styling, and interactions across files.

## Notes

- No build step is required.
- Internet connection is recommended for Tailwind CDN and any external assets used by individual pages.

## Purpose

This repository is intended for quick visual comparison of different landing page outputs for the same prompt and theme.
